01

Model currency

Every GPU/NPU device receives verified model updates — publisher-signed, validated, logged to a public ledger, revocable the moment a fault is found. Models ship like container images.

02

Mesh enrolment

A new device joins the mesh with one confirmation — the zero-config discovery a printer uses — declares what it can carry, and accepts work sized to that, the way Matter commissions a lamp.

03

Gateway recognition

The mesh answers as one endpoint speaking an open API/MCP dialect — so any AI client can plug in without a driver, a subscription or anyone’s permission.

04

Neutral custody

The spec lives in a vendor-neutral body, with a certification mark consumers can trust — and, where industry stalls, a legislature to finish the job, as Europe did with the charger.

What remains to build is small.

End to end, the gateway routes each request to the device holding the right model — and a model too big for one machine can split its layers across several. A capability record, a scheduler, a matching layer — then specification and conformance, the Institute’s first mandates.

The engineering

ENKI-1 — the wire protocol, drafted like we mean it.

Standards die as slideware, so here is the actual mechanism — how a model reaches a device, verifiably, over the mesh. Six moving parts, each one boring, proven plumbing borrowed from systems that already run the world: signed software updates, torrents, binary diffs.

ENKI-1 — the draft, in full

01 · Device profile

Every participating device describes itself once, in a small JSON document signed by its own key: available memory, accelerator and rough TOPS, supported quantisation formats, thermal budget and uptime pattern. The profile maps the device to a registry class — org, desktop, laptop or edge — so it is only ever offered models it can actually carry. The profile is shared with the gateway its owner enrols in, and nothing else.

02 · Signed snapshots

The registry publishes a signed snapshot: the list of current model revisions, their hashes, and their device-class mappings. The trust chain is TUF-style — an offline root key, release signatures from a rotating quorum of member seats, and short-lived timestamp keys so a stale mirror is detectable. A device verifies the full chain before it downloads a single byte of weights. No valid chain, no download — there is no manual override to socially engineer.

03 · Content-addressed weights

Weights are chunked at 64MB and each chunk is addressed by its BLAKE3 hash. A device fetches chunks from the nearest peers that already hold them — the laptop on the same LAN before the neighbourhood node, the neighbourhood before the backbone — torrent-style, resumable, every chunk verified against the signed manifest. The datacenter becomes the seed of last resort, not the toll booth.

04 · Delta updates

A model refresh ships as a binary diff against the previous revision of the same quantisation. Post-training nudges touch a fraction of the tensors, so a typical refresh is a slice of the full artefact — the difference between model currency being a nightly fact and a monthly chore on home bandwidth. Devices that fall several revisions behind fetch the full artefact and rejoin the diff chain.

05 · Revocation and rollback

When a fault is confirmed, the same quorum signs a revocation entry. It propagates through mesh gossip; devices pin their last-known-good revision and roll back without asking. There are no silent pushes in either direction — every change, forward or back, lands in the public ledger with the signatures that authorised it.

06 · Capability handshake

An enrolled device answers as one OpenAI-compatible endpoint plus a /capabilities document: context length, modalities, a rough tokens-per-second figure. Clients read it and negotiate — no drivers, no vendor SDK, no permission from anyone. A model too large for one machine advertises itself through the gateway, which splits layers across the devices that volunteered for it.

Status: draft. ENKI-1 is written to be torn apart in public — the RFC lives in the open repository, and the first conformance suite is the Institute’s mandate before any logo goes on any box.
