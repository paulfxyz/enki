03 · The standard

One standard away.

The local AI datacenter is not blocked by physics or price — only by a missing agreement. Four clauses, each already running somewhere for lightbulbs, chargers or chat, make every GPU/NPU device a citizen of your mesh.

Four clauses — each already
running somewhere.

01

Model currency

Every GPU/NPU device receives verified model updates — publisher-signed, validated, logged to a public ledger, revocable the moment a fault is found. Models ship like container images.

02

Mesh enrolment

A new device joins the mesh with one confirmation — the zero-config discovery a printer uses — declares what it can carry, and accepts work sized to that, the way Matter commissions a lamp.

03

Gateway recognition

The mesh answers as one endpoint speaking an open API/MCP dialect — so any AI client can plug in without a driver, a subscription or anyone’s permission.

04

Neutral custody

The spec lives in a vendor-neutral body, with a certification mark consumers can trust — and, where industry stalls, a legislature to finish the job, as Europe did with the charger.

What remains to build is small.

End to end, the gateway routes each request to the device holding the right model — and a model too big for one machine can split its layers across several. A capability record, a scheduler, a matching layer — then specification and conformance, the Institute’s first mandates.
