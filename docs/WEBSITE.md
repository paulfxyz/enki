# The website

Enki is a multi-page site using HTML, CSS and JavaScript, with a PHP page router and a separate PHP/SQLite submissions endpoint. There is no frontend framework; a small build step materializes localized HTML. The website is implemented, while the AI device, mesh and Institute it describes are proposals.

## Structure

- **Pages:** `index.html`, `manifesto.html`, `device.html`, `client.html`, `standard.html`, `institute.html`, `join.html`, `models.html`, `apply.html`, `simple.html` and `privacy.html`.
- **Presentation:** `base.css`, `style.css` and `swiss.css` provide the layered styles. Clean public URLs omit `.html`; the hosting configuration must resolve them.
- **Behaviour:** `app.js` handles shared controls and forms; `apply.js` implements the founding-seat wizard; `simple.js` renders the short explanation and narration. Reached wizard steps are native buttons supporting click, tap and keyboard navigation, with unreached steps disabled. Forward jumps and submission revalidate prior answers, and the review refreshes after edits. The public-profile link hint sits below its input in every language.
- **Catalogue:** `registry-en.js` supplies the shared fifty-model catalogue; each language dictionary translates its prose while preserving model identities and values. `data.js` retains legacy structures. Explicit scenario estimates and rounded cost ratios are not verified savings; see [methodology](COST-ESTIMATES.md). Hardware qualifications use full-width notes, and one collapsible assumptions panel includes the uncertainty disclaimer.
- **Languages:** release 100 brings the changed source content, oversight proposal, privacy/form clarifications and Registry qualifications to all twenty languages. French, Spanish, Simplified Chinese and Russian received a full active-copy premium revision and independent source-grounded review. The other fifteen translations received a reviewed changed-content update, retaining accepted existing text. Locale-prefixed localized slugs remain authoritative, independent of saved preferences; old `?lang=<code>` links redirect to canonical paths. Arabic, Hebrew and Urdu use right-to-left layout. Translation and editorial work use the approved OpenRouter route.
- **Media:** all twenty simple-page narrations follow the six-part explanation: manifesto, protocol, client, Registry, device and Institute, followed by project status. Release 100 uses a single continuous take per language through OpenRouter with Gemini 3.8 Flash TTS and the friendly male Achird voice, rather than joining separate sections. Whole-file loudness normalization preserves continuous delivery; output is 128 kbps MP3. French synthesis uses a phonetic cue for Enki, pronounced /ɛn.ki/ like “haine-qui”; the visible name stays unchanged. Automated audio review checks content, continuity, cutoffs and pronunciation, with acceptance evidence and any exceptions in the release QA record. It is not native-human certification. The simple page never initializes the arrival film, locks scrolling for it or starts narration automatically.
- **Oversight:** a localized, keyboard-accessible dialog opens from the landing page, manifesto, Institute and simple explanation. It distinguishes frontier/datacenter-intensive AI from everyday intelligence and describes use/risk assessment, adaptation and testing, independent review and applicable law, limited deployment, and continued monitoring. The Institute's evaluation role and avoidance of a single point of failure remain proposals, not existing capabilities.
- **Landing and motion:** the six programme cards follow Manifesto, Device, Client, Standard, Institute, Registry. Manifesto and Device each occupy a full-width row, followed by Client beside Standard and Institute beside Registry. Hardware keeps its landscape framing; the final pair uses matching 4:3 illustration frames without cropping the artwork. Section numbers are synchronized across all languages; global navigation order is unchanged. Client, Registry and Institute art follows the existing illustration family. The Client diagram has blue inward and green outward particles on both sides; reduced-motion preferences pause its SVG animation.
- **Manifesto:** the main final appeal remains in Article X. The reworked postface develops the mythology, the caution about tools and wisdom, and the closing boat metaphor. Release 98 expands Article VIII in English and French: affordable consumer GPUs, NPUs, memory and maintained runtimes worldwide, with a future role for suitable embedded devices. Google AI Edge, STM32N6 and Qarnot illustrate existing adjacent technologies, not a completed household mesh. Three new primary references bring the inventory to 101.
- **Membership:** The 300 page explains the founder-backed open call and existing small working group, the policy of no public member directory with optional self-identification by admitted members, and a continuing candidate pool for the proposed 10% annual rotation at full membership: 30 out and 30 in. These additions are localized across all twenty languages; they do not assert that 300 members are already seated.

## Local review

Run `npm ci` and `npm run build:locales` after editing source HTML, dictionaries, simple-page data or the route map. Then use `php -S 127.0.0.1:8092 router.php` for local page routing, or Apache with `.htaccess` enabled to exercise production rewrites too. Generated locale directories are static preview counterparts only; production reads `assets/i18n/pages-<lang>.json` through `router.php`. See [localized routing](LOCALIZED-URLS.md) for deployment order and checks.

Published domains use the production submissions endpoint; review previews block submissions before sending anything. Localhost uses a local endpoint. During automated testing, intercept requests with mocks; never submit fabricated applications to production. To test actual storage, run the PHP endpoint in an isolated directory with its own database outside the served root.

## Submissions

The browser sends JSON in a form-encoded field to `https://enki.ngo/api/submit.php`. The dedicated application caps the combined JSON at 5 MiB, while the server accepts up to 6 MiB of JSON and a 9 MiB transport body. Hosting limits may be lower and must be verified during deployment.

The browser requires a successful response and `ok: true` before showing receipt. On error it keeps the answers on the page; those answers are not guaranteed to survive reload or tab closure. The backend stores submissions in SQLite outside the web root and rate-limits using a pseudonymous IP hash. The English privacy notice names Paul Fleury as interim controller; the approved application-retention ceiling is twelve months. `api/retention.php` is an hourly CLI cleanup job, with a second cleanup before writes/exports. Read [privacy operations](PRIVACY-OPERATIONS.md) for deployment and processor checks; hosting logs and recovery copies remain separate.

## Release checks

- **Language coverage:** validate active keys, placeholders, HTML, references, model facts, diagrams, metadata and narration together across the twenty supported languages.
- **Compatibility:** inspect desktop/mobile layouts, both themes and language switching; do not equate loaded translations with editorial parity.
- **Forms:** test validation, edit/back navigation, attachment limits, storage acknowledgement, server failures and retained answers.
- **Deployment:** bump asset versions consistently, commit the tested working revision, and review a private preview before publishing. A local commit or preview is not evidence that either public domain changed.
